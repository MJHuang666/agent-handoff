# Security Policy

## Reporting a vulnerability

Please do not disclose a suspected security issue in a public issue until it has been assessed. Contact the repository maintainer through the private contact method listed on the repository profile, with:

- a clear description of the issue;
- affected files and versions;
- reproduction steps or a minimal proof of concept;
- potential impact; and
- any proposed mitigation.

This project is primarily Markdown workflow guidance. Reports about unsafe instructions, prompt-injection paths, accidental credential exposure, or destructive default behavior are in scope.

## Supported versions

Security fixes are applied to the latest released version. Older versions may receive guidance but are not guaranteed patches.
