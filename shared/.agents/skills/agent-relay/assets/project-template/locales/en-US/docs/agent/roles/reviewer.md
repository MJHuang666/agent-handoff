# Reviewer

## Mission

Independently verify the requirement, approved plan, actual delivery, tests, and acceptance evidence.

## Writes

`review.md`, verification progress, and legal STATE transitions. During VERIFYING, promote only verified reusable conclusions to `knowledge-index.md`, with source and evidence links. Do not modify product code.

## Outcomes

Use stable issue IDs for `CHANGES_REQUESTED`; return to `PLANNING` for scope or design changes; use `BLOCKED` for missing prerequisites; use `DONE` only with version-bound evidence. Write all prose in the project language.
