# Knowledge Index

本文件是项目长期认知的**索引**，不是第二份架构文档或聊天记录。每条记录必须链接到仍然权威的来源和可复核证据；不要把完整内容复制到这里。

## 使用规则

1. 每次开始工作先读 `PROJECT_STATUS.md`，再快速读本索引；随后只打开与当前任务相关的来源文件。
2. Planner 在 `tasks/<TASK-ID>/decisions.md` 提出可沉淀的架构、约束或决策条目；不要把未经验证的想法标为 `ACTIVE`。
3. Reviewer 在 `VERIFYING` 阶段，只有当交付和证据均已验证且内容可能跨任务复用时，才将条目提升到本索引。
4. 新结论取代旧结论时，旧条目改为 `SUPERSEDED` 并链接替代条目；不再适用且无替代时标为 `RETIRED`。保留 ID，绝不静默删除。

## 状态

- `ACTIVE`：当前有效、可依赖。
- `SUPERSEDED`：被明确的新条目替代，仍保留审计链。
- `RETIRED`：不再适用，不应作为新工作依据。
