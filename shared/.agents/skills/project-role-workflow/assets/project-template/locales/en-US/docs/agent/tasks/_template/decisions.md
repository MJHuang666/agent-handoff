# Decisions

## Decision Record Format

### ADR-001: <title>

- Date: <ISO-8601 date>
- Status: PROPOSED | ACCEPTED | SUPERSEDED
- Decision: <Decision>
- Reason: <Why>
- Rejected: <Alternatives considered and rejected>
- Constraints: <Long-term constraints>
- Authorization Ref: <Explicit approval source>
- Supersedes: null

Accepted decisions are never silently deleted; superseded decisions remain as history.
