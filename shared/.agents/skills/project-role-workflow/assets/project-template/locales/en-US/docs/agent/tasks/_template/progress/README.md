# Progress Records

Name records `NNN-<action>-<tool>.md`. Create once; never overwrite or rename.

Every record states the task, role, participant, stage round, revisions, inputs, actions, conclusions, evidence, unresolved items, and the next participant. Use the project language for prose. A CHECKPOINT also records unfinished actions, running processes, side effects, and the next safe read-only check. Agent replacement uses `kind: MANAGEMENT` and records the transaction ID, scope, old/new participants, reason, authorization, and input/output revisions.
