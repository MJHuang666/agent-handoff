# Decisions

## Decision Record Format

### ADR-001: <title>

- Date: <ISO-8601 date>
- Status: PROPOSED | ACCEPTED | SUPERSEDED
- Decision: <决定内容>
- Reason: <为什么这样决定>
- Rejected: <考虑并拒绝的替代方案>
- Constraints: <由此产生的长期约束>
- Authorization Ref: <真实批准来源>
- Supersedes: null

计划可以演进；已接受决策不得静默删除。被替代时保留旧记录并写新 ADR。
